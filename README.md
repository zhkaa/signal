# Signal · by Obsidia

Рабочее пространство для авторов YouTube: исследование ниш, сравнение каналов, подготовка публикаций и сохранённые проекты. Публичный лендинг объясняет продукт; инструменты доступны после входа.

Стек: Alpine.js, Express, Supabase/PostgreSQL. Локальные Geologica (кириллица и латиница), Lucide и оригинальная иллюстрация. RU/EN интерфейс. Деморежим удалён.

## Локальный запуск

Node.js 24:

```powershell
npm ci
if (!(Test-Path .env)) { Copy-Item .env.example .env }
npm start
```

Откройте [localhost:3000](http://localhost:3000). Сервер слушает 127.0.0.1; внешний хостинг не настроен. APP_URL должен совпадать с адресом в браузере, включая порт: это источник проверки Origin и адресов возврата OAuth.

В этой рабочей копии проект Supabase уже записан в исключённый из Git .env. Для другого клона заполните SUPABASE_URL, SUPABASE_PUBLISHABLE_KEY и YOUTUBE_API_KEY. Старое имя SUPABASE_ANON_KEY поддерживается для совместимости. Publishable key — правильный публичный ключ; service_role/secret и пароль базы приложению не нужны.

## Настройка Supabase и Google

[Пошаговая инструкция](docs/setup.md). Для новой базы выполните `npm run db:prepare`, затем вставьте `supabase/setup.sql` в Supabase SQL Editor. Скрипт создаёт таблицы, RLS, роли, объявления и журнал администратора одним transaction. Для существующей базы применяйте только отсутствующие миграции: не запускайте весь setup повторно.

Авторизация: email/пароль и Google OAuth PKCE; подтверждение почты, восстановление пароля, серверные HttpOnly-cookie, обновление сессии и выход. Подтверждение почты и восстановление открывайте в том же браузере, где начали действие. Google появится доступным только после включения провайдера.

Admin v1: список профилей с пагинацией, число проектов, состояние интеграций, двуязычное объявление, журнал его изменений. Роль назначает владелец проекта через SQL Editor. Самостоятельного повышения роли, удаления пользователей, платежей и impersonation нет. [Модель прав](docs/permissions.md).

## Возможности и ограничения

| Раздел       | Поведение                                                                         |
| ------------ | --------------------------------------------------------------------------------- |
| Дашборд      | Сохранённые проекты, исследования текущей сессии, быстрые действия                |
| Поиск ниш    | Четыре тематические выборки, до 10 видео каждая; средние просмотры                |
| Конкуренты   | До 6 каналов на запрос, сравнение до 4 каналов                                    |
| Оптимизация  | Шаблонные заголовки, описание, теги и чеклист для видео, канала, трансляции       |
| Статистика   | Публичные суммарные показатели каналов                                            |
| Мои проекты  | Сохранение в Supabase, открытие и подтверждённое удаление; 12 записей на страницу |
| Настройки    | Имя профиля, восстановление пароля, статус настройки сервисов                     |
| Админ-панель | Доступ через проверку роли на сервере и RLS                                       |

Оптимизатор не является генеративным ИИ. Просмотры выборки не прогнозируют спрос или доход. CTR, удержание, публикация видео и OAuth-доступ к личному каналу не реализованы. Поиск требует серверного YouTube Data API key; без него интерфейс показывает отсутствие подключения, а не учебные данные.

## Проверка

```powershell
npm test
npm run format:check
npm run build
```

API-тесты используют изолированный локальный тестовый сервис, проверяют авторизацию, PKCE, cookies, CSRF, права администратора, пагинацию, сохранение/удаление, ошибки БД и конфликты объявлений. Они не доказывают работу внешних Google/YouTube или корректность RLS удалённой базы. [Отдельная проверка облачной БД](docs/database-checks.md).

Для воспроизводимого браузерного QA: `node scripts/test-preview.mjs`. Это отдельный тестовый сайт на порту 3100 и disposable данные в памяти; он не подключён к реальному Supabase и никогда не включается в npm start. Тестовые аккаунты перечисляются в его терминале.

## Структура и команда

- src/client — интерфейс, локализация, shared CSS и функции.
- src/server — API, проверка сессий и интеграции.
- supabase/migrations — canonical SQL; setup.sql генерируется из них.
- public — результат сборки, не редактируется вручную.
- DESIGN.md, UX-CONTRACT.md — дизайн и поведение.
- tests — проверки API и тестовый сервис.

Исходная команда: zhkaa — фронтенд, Asik2good — сервер, danik1dotcom — база данных. [Архитектура](docs/architecture.md).

По материалам задания рк1 требуется отдельный публичный деплой; текущая задача пользователя — локальная версия, поэтому сайт не опубликован.
